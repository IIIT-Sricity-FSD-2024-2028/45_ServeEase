## Description

ServeEase Backend is the server-side application powering the **ServeEase – Service Provider Discovery & Booking Platform**.

It provides RESTful APIs for managing customers, service providers, bookings, support requests, and administrative operations. The backend follows a modular NestJS architecture with in-memory CRUD operations, request validation, Swagger API documentation, and role-based access control (RBAC). :contentReference[oaicite:0]{index=0}

## Features

- Modular NestJS architecture
- RESTful APIs
- Role-Based Access Control (RBAC)
- In-memory CRUD operations
- DTO validation with `class-validator`
- Request transformation with `class-transformer`
- Interactive Swagger documentation
- Jest testing support
